# 到点 Android · 1.1-rc2

原生 Android 应用，支持企微上下班真实打卡和独立的界面测试模式。当前真实提交适配企业微信 5.0.13（versionCode 84802），在小米 MI 9 / Android 13 验收。

## 已实现

- 手动选择上班／下班及执行模式；上下班独立定时、固定／随机时间、星期、跨日、延迟继续当天。
- 真实执行先进入企微当日统计。使用年月、截图中的选中日和星期列核对日期；同周选错日期时选择当天并重新等待加载。
- 将真实记录中的日期、类型、时间、状态一起匹配。已有记录时只保存核验结果，不更新原记录。
- 当前企微的无固定时段通用“拍照打卡”规则：没有上班记录时才允许上班；已有上班且没有下班记录时才允许下班。需要在设置中确认本人使用这一规则。无法判定入口或遇到未适配版本时停止。
- 识别相机取景和照片确认页面，拍摄当前真实画面并确认。照片确认前原子保存提交保护；在确认之后发生断网、超时、中断或进程重启时，只检查记录，不自动再次提交。
- 核验成功后保存企微当日统计截图，记录实际状态（不会把异常改成“正常”）。真实邮件使用这些字段，界面测试邮件明确标为未提交。
- SQLite 执行记录及独立的日期＋类型提交保护；邮件按真实记录指纹去重；邮件发送结果不明时不自动重发。
- Android Keystore 加密邮箱授权码、QQ TLS SMTP、正文 CID 内嵌截图、连接测试、失败邮件单独重发。
- 开机、升级、系统时间变化后的计划恢复；真实休眠时先等待唤醒页面显示和普通锁屏解除，再启动企微。

## 使用与默认配置

1. 安装后开启到点无障碍、精确闹钟和通知权限。
2. 小米系统中允许自启动、锁屏显示、后台弹出界面，设置省电策略为“无限制”，并取消 Android 电池优化。首次从到点冷启动企微时，在小米弹窗中选择“始终允许”。
3. 若企微使用已核对的无固定时段通用拍照规则，在设置中勾选对应说明。其他规则和其他企微版本需要另外适配。
4. 手动执行的确认页明确显示“真实打卡”或“界面测试”和本次类型。
5. 按需填写 QQ 邮箱和 SMTP 授权码。安装包不包含邮箱授权码或手机密码。
6. 核对运行模式、上下班时间后，分别开启计划和首页全局开关。切换定时模式会关闭全局开关。

首次安装和从 1.0 界面测试版升级时，定时默认关闭。既有界面测试记录保留，并与真实记录区分。邮箱不预配置。

应用不输入手机密码、不绕过安全锁。设置安全锁后，遇到锁定会停止。系统的强行停止应用、关闭无障碍、权限撤销或企微页面变化仍可能阻止无人值守运行。

## 构建

JDK 17、Android SDK 35、Build Tools 35.0.0、Gradle 8.7。支持 Android 11+。

```sh
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。默认首次构建创建 `.local/debug.keystore`；源码包不含签名私钥。更新手机上的既有应用应沿用原签名，不能以卸载替代更新。可通过 `DAODIAN_DEBUG_KEYSTORE=/path/to/existing/debug.keystore` 指定既有签名。

中文文字识别模型随 APK 打包，在设备本地处理截图，不依赖手机安装 Google Play Services。[ML Kit 官方接入文档](https://developers.google.com/ml-kit/vision/text-recognition/v2/android)

## 测试与验证范围

```sh
# JVM 测试、静态检查与 APK 构建
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug

# 连接测试设备后运行数据库和日期识别测试
./gradlew :app:connectedDebugAndroidTest
```

已在小米 MI 9 / Android 13 验证真实下班拍照提交、已有记录读取与去重、日期校验、休眠唤醒、重启计划恢复，以及 30 分钟息屏待机后的闹钟触发。测试源码包括 JVM 核心测试和设备数据库／OCR 测试。日期识别样例仅保留日历区域，不含员工记录或照片。

首条上班记录的新建流程仍需在当天没有上班记录时验收；隔夜、多日待机，以及更多 Android／企微版本不在已验证范围。固定班次、多班次和跨周／跨月日期选择仍可能需要额外适配。识别不完整时应用会停止。

## 仓库内容

版本控制保留应用源码、Gradle Wrapper、资源和字体许可、测试及必要样例。构建产物、APK、签名私钥、本机 SDK 配置、IDE 文件、设备数据库、运行截图、日志和交付压缩包由 `.gitignore` 排除。邮箱授权码由用户在设备上输入，经 Android Keystore 加密保存，不属于仓库内容。

## 调试接口

调试接收器要求 `android.permission.DUMP`，release 构建拒绝调用。界面测试闹钟固定 TEST 模式；真实验收命令还要求显式类型和确认参数。重启测试临时使用普通 TEST 计划，结束后自动恢复之前的配置。截图导出仅从本机已保存的执行记录读取。
